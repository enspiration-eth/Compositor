# Models

`u2netp.onnx`: U²-Net (small, "u2netp") salient object detection, by Xuebin Qin et al.
(https://github.com/xuebinqin/U-2-Net), Apache License 2.0. ONNX export from rembg
(https://github.com/danielgatis/rembg, MIT). Used by Remove Background, Select Subject and Object Selection in place of
Apple's Vision framework, and run on-device with onnxruntime-web (MIT).
